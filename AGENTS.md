# Правила для агентов в этом репозитории

## Обязательная схема исправления висячих предлогов

Все русские тексты, которые видит человек (лендинг, оферта, документация, тексты навыков и интерфейса), проходят через неё перед сдачей. Решение владельца от 18.10.2026.

- Предлоги, союзы и частицы из 1–2 букв («в», «с», «и», «по», «на», «не») и короткие служебные слова («при», «для», «без», «над», «под», «про», «или», «что»…) приклеиваются к следующему слову неразрывным пробелом.
- Числа приклеиваются к следующему слову: «4 региона», «15 лет», «$20 в месяц», «300+ человек».
- Перед тире «—» стоит неразрывный пробел; «бы», «ли», «же» приклеиваются к предыдущему слову.

Как применять, после любой правки текста:

```sh
python3 scripts/nbsp.py landing/index.html landing/oferta/index.html   # исправить
python3 scripts/nbsp.py --check <файлы>                                 # проверить, код 1 = есть висячие
```

Скрипт обрабатывает только видимый текст: теги, атрибуты, код, ссылки и фронтматтер не трогает, повторный запуск ничего не меняет. Для ёлочек и тире дополнительно можно прогнать навык «Мильчин» (milchin), но висячие предлоги закрывает именно `scripts/nbsp.py`. Тексты, которые JS вставляет в страницу, правьте вручную с символом U+00A0.
