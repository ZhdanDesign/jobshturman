# Админка сервера ключей JobShturman

Статическая страница на русском поверх API сервера ключей (`key-server/API.md`): вход по токену администратора, список ключей с фильтром по статусу и поиском, карточка с устройствами и журналом событий, выдача после оплаты, продление, блокировка и разблокировка, отвязка одного устройства и сброс всех, редактирование тарифов, сводка и версии методики с загрузкой нового пакета. Без сборки, CDN и зависимостей.

Адрес: `https://tools.owai.ru/jobshturman/_/admin/`. API ищется по относительному пути `../../keys/v1/admin` (константа `API_BASE` в `app.js`), то есть `/jobshturman/keys/v1/admin` на том же домене, поэтому CORS не нужен. Страницу отдаёт nginx из `/var/www/hrshturman-admin/`; туда копируются `index.html`, `app.js`, `styles.css`, `tokens.css`.

Токен администратора вводится на экране входа и хранится в `sessionStorage` этой вкладки; запросы идут с `Authorization: Bearer`. Ответ 401 или 403 удаляет токен и возвращает на вход. Кнопка «Выйти» удаляет токен и сбрасывает адрес раздела. До входа на странице только карточка «Вход»: меню, шапка, подвал и разделы появляются в DOM после входа, запросов к API до входа нет. Страница закрыта от индексации (`meta robots` и заголовок nginx `X-Robots-Tag`). Ошибки API показываются из поля `message`.

Полный ключ приходит только в ответе на выдачу: он показывается один раз и удаляется из памяти и DOM при закрытии окна. Сервер хранит хэш ключа, начало ключа (`key_hint`), устройства как начало хэша установки и номер заказа. Статусы считает сервер: «Истекает» — меньше суток до конца. Срок «до даты» — конец выбранного дня по местному времени браузера.

## Методика и главный промпт

Вход тем же экраном, роль определяет `GET /whoami`. Токен автора методики (`HRS_KEYS_METHODOLOGIST_TOKEN`) открывает только разделы «Методика», «Главный промпт» и «Версии»; администратор видит всё.

- «Методика» — черновик на сервере: проверка (ошибки не дают опубликовать), маршрут (шаги, этапы по порядку, перенос стрелками, новый этап по шаблону, выключение, версия методики), файлы по этапам с редактором, загрузка zip (заменяет черновик) или отдельного файла, «Взять опубликованную версию», «Скачать черновик», история с изменениями и возвратом любой версии. Публикация — «тестовым» или «всем».
- «Главный промпт» — редактор `agent/genesis.md`: правила, которые агент читает первыми.
- «Версии» — опубликованные пакеты с метками каналов; «Тестовым» и «Всем» делают версию текущей, это же откат. Загрузка готового zip — только администратору.
- В карточке ключа кнопка «Сделать тестовым» переводит ключ на тестовые версии.

Каждое сохранение — новая версия черновика; сохранение передаёт `base_sha` открытого файла, поэтому чужая правка из другой вкладки не перезаписывается (ответ 409 показывается как ошибка формы).

## Дизайн-токены

`tokens.css` — подмножество официальных токенов [OpenAI Apps SDK UI](https://github.com/openai/apps-sdk-ui), **MIT © OpenAI**. Это публичная система интерфейсов ChatGPT; отдельной публичной системы Codex нет. Локальный источник: `/Users/zhdanparfenov/Code/06_tools/Tools/design-systems/openai-codex/`, файлы `source/variables-primitive.css`, `variables-semantic.css`, `variables-components.css`; проверено по `tokens.json` и документации Colors, Typography, Dark-mode. Неофициальные материалы `reference-thirdparty/` не использованы.

Взяты нейтральная шкала gray и нужные green/orange/red/blue; семантические поверхности, текст, границы, focus ring и цвета статусов; системные шрифты, размеры/интерлиньяж, веса, радиусы и шаг отступов; параметры button, badge, input, alert и dialog. `alpha()` заменена стандартной `color-mix()`, `spacing()` — `calc(var(--spacing) * n)`; значения сохранены. MIT notice включён в `tokens.css`. В `styles.css` нет самостоятельной палитры.

## Проверки

```sh
node --check key-server/admin/app.js
node --test key-server/admin/app.test.cjs
grep -nE '#[0-9a-fA-F]{3,8}\b' key-server/admin/styles.css
grep -niE 'email|почт|телефон|фио' key-server/admin/*.js key-server/admin/*.html
```

Обе команды `grep` должны завершаться с кодом 1 и без вывода.

`app.test.cjs` проверяет логику и обработчики с заглушками DOM и `fetch`; тестовые ключи и тарифы есть только в нём. Отрисовку проверяет прогон в браузере против `hrs-keys serve`.
