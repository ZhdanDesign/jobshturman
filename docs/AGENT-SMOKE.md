# Смоук агентов: Claude Code и Codex

Проверяет стыки с настоящими агентами: агент видит инструменты hrs, принимает ключ, читает этап 0, сохраняет режим ответов и начинает анкету. Итог берётся из данных hrs, а не из слов агента. Методику не проверяет: для неё `hrs selftest`, для рантайма — `tests/test_route.py`.

Каждый агент получает только MCP-сервер hrs, временную папку данных, временную связку ключей и локальный сервер ключей с настоящей библиотекой. Боевой сервер и ваши сохранённые MCP-настройки не используются. Один прогон расходует несколько тысяч токенов подписки на агента.

## Один раз: вход в отдельных папках

Чтобы не трогать `~/.claude` и `~/.codex`, войдите в аккаунты в отдельных папках:

```bash
mkdir -p ~/.hrs-smoke/claude ~/.hrs-smoke/codex
CLAUDE_CONFIG_DIR=~/.hrs-smoke/claude claude      # внутри /login, потом /exit
CODEX_HOME=~/.hrs-smoke/codex codex login
```

## Запуск

```bash
cd hrs
CLAUDE_CONFIG_DIR=~/.hrs-smoke/claude CODEX_HOME=~/.hrs-smoke/codex \
  uv run --frozen python tests/agent_smoke.py claude codex
```

`scripted` вместо имени агента прогоняет те же шаги без модели и проверяет сам смоук. Без переменных агенты берут ваши обычные папки: MCP-настройки не меняются, но журнал сессии появится в `~/.claude` и `~/.codex`.

Результат по агенту: `PASS`, `FAIL` с проверкой, которая не прошла, или `BLOCKED`, если агент не вошёл в аккаунт.
