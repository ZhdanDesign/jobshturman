# HR Штурман: инструкция тестировщику

Спасибо, что помогаете. Тест занимает 20–30 минут. Нужен Mac с Claude Code или Codex и ключ доступа, который вам прислали.

## 1. Установка

В Терминале:

```bash
curl -fsSL https://raw.githubusercontent.com/ZhdanDesign/hrshturman/main/install.sh | sh
```

В конце установщик печатает отчёт: у `claude` и `codex` должно быть `added` или `already`. Потом полностью закройте и откройте Claude Code или Codex.

## 2. Ключ и первый этап

1. В новом чате напишите: «HR Штурман».
2. Агент попросит ключ. Вставьте его. Агент ответит, что ключ активен, и назовёт тариф и срок.
3. Агент спросит, где отвечать: в чате или в окне браузера. Попробуйте браузер.
4. Напишите «начни этап 0» и пройдите анкету: что мешает в поиске, цель, как идёт поиск, условия. В конце подтвердите карту запроса.

## 3. Что проверить

- Установка прошла без ручных шагов, кроме перезапуска агента.
- Ключ принят с первого раза. Неверный ключ даёт понятную ошибку.
- Анкета в браузере открывается, ответы сохраняются, агент в чате их видит без переспрашивания.
- Этап 0 доходит до карты запроса и подтверждения.
- По желанию дальше: загрузите своё резюме (PDF или Word) — агент разберёт его на факты.
- Агент не выдумывает опыт и цифры, которых вы не давали.

## 4. Куда писать

Пишите в чат тестирования, где вам прислали ключ. Полезно приложить:

- что делали и что ожидали;
- скриншот;
- вывод команды `hrs license` (ключ в нём скрыт, показываются только первые 4 знака).

Не присылайте полный ключ и личные документы.

## Удаление

```bash
claude mcp remove hrshturman --scope user
uv tool uninstall hrshturman
rm -rf ~/Library/Application\ Support/HRShturman ~/.claude/skills/hrshturman ~/.agents/skills/hrshturman
```

В Codex удалите блок `[mcp_servers.hrshturman]` из `~/.codex/config.toml`.
